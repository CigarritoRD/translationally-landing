# TranslationAlly

Este repositorio contiene el sitio público bilingüe de TranslationAlly, desarrollado con React, TypeScript, Vite y Tailwind CSS. La ruta `/` muestra la página principal y enlaza al portal externo de traducción.

## Skills del proyecto

Usa el catálogo de skills de la sesión y lee el `SKILL.md` correspondiente antes de trabajar en cada tarea aplicable.

| Skill | Cuándo usarla |
| --- | --- |
| `modern-web-guidance:modern-web-guidance` | Primero en tareas de HTML, CSS o JavaScript del cliente, como cambios en la navegación, el formulario o la accesibilidad web. |
| `design-taste-frontend` | Siempre que la tarea implique diseño web, incluidas páginas completas, secciones, componentes, ajustes visuales y vistas previas. Úsala también cuando corresponda otra skill de diseño o implementación. |
| `ui-ux-pro-max` | Al diseñar, revisar o corregir componentes, diseño adaptable, accesibilidad o interacción. |
| `playwright` | Al verificar flujos en un navegador, como el cambio de idioma, el menú móvil, la navegación o el formulario. |
| `supabase` | Cuando la tarea involucre Supabase, por ejemplo, al integrar autenticación o una base de datos. La dependencia está declarada en el proyecto. |
